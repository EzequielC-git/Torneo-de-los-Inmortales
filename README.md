## Presentación

Este repositorio contiene el desarrollo del **Trabajo Práctico N° 2** de la materia *Paradigmas de Programación* realizado por el **Grupo XI**. El proyecto modela un sistema de torneo eliminatorio por parejas entre cultivadores de distintas escuelas, aplicando los principios de la Programación Orientada a Objetos (herencia, polimorfismo, interfaces, manejo de colecciones, excepciones y patrones de diseño).
